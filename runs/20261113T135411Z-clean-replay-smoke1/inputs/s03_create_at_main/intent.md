# Open new work orders at MAIN, never approve or cancel

Our maintenance agent may raise new work orders for the MAIN site, for example when it spots a fault on a pump or chiller.

- It may open new work orders, but only for MAIN, never for another site.
- It must never approve a work order and never cancel one. Approving and cancelling stay with people.
- Opening new work orders is the only thing it may do. It must not change, assign or close existing work orders, and nothing else is granted.
